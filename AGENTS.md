# CSIS 312 course context

This repository holds Tate's Liberty University CSIS 312 slides, instructor examples,
and JavaFX manual excerpts. Before helping with course work, read README.md and
reference/COURSE_GUIDE.md, then consult the relevant source and extracted text.

- Tate expects JavaFX for most assignments. Prefer JavaFX for GUI work unless the
  assignment explicitly says otherwise. The supplied slides teach Scene Builder,
  FXML and controllers; follow the required approach for each assignment.
- Treat the assignment prompt and rubric as the requirements. Do not infer required
  Java/JavaFX versions, IDE, build tool, naming rules or submission format from old slides.
- Anchor explanations in supplied examples, citing source filename and slide/page
  when useful. Keep solutions at the demonstrated course level and explain any new technique.
- Preserve the original course documents. Extracted text is a search aid, not a
  replacement: diagrams and image-based code may be absent, and OCR may be wrong.
- Verify suspicious code against the original before adapting it. Some examples
  are intentionally incomplete or demonstrate errors; do not assume they compile.
- The Chapter 8 deck, slide 3, states that AI use in assignments is academic fraud.
  Keep this recorded course rule visible when discussing permitted assignment help;
  do not misrepresent AI-generated work as the student's independent work.
- Record new course materials and changed preferences in this repository. These
  files provide persistent context when the repository is available; do not claim
  permanent model memory or access in unrelated chats.
